ยังไม่ได้ตรวจการเชื่อมต่อ

1. ข้อมูลเอกสาร

ใช้ JSON คำขอที่มี docKey และข้อมูลตัวแปร ระบบจะอ่าน Contract และล็อกเวอร์ชันก่อนส่ง

ชื่ออ้างอิงต้องตรงกับค่าตัวแปรภาพใน JSON ใช้ชื่อไฟล์ที่ตัดนามสกุลออกเป็นค่าเริ่มต้น แก้ได้ด้านล่าง

อัปโหลดทีละไฟล์ก่อนส่งงานพร้อมกัน • ไม่มีการส่ง POST ซ้ำอัตโนมัติ • ข้อมูลไม่ถูกบันทึกในเบราว์เซอร์

Contract ที่ API ส่งกลับ
ยังไม่ได้อ่าน

2. ติดตามงาน

แสดงขั้นตอนและจำนวนที่ API รายงาน ไม่ประมาณเปอร์เซ็นต์หรือเวลาที่เหลือ การปิดหน้านี้ไม่ยกเลิกงานบนระบบ

เกี่ยวกับการดาวน์โหลดและข้อผิดพลาด

ไฟล์อาจถูกลบหลังดาวน์โหลดสำเร็จหรือหมดอายุ ตามการตั้งค่า Service ควรบันทึกไว้ทันที หน้านี้ไม่ดาวน์โหลดให้เอง

คิวเต็ม: รอแล้วส่งใหม่ได้ • ข้อมูลผิด: แก้ตาม code/path • ชุดรูปหมดอายุ: เตรียมใหม่ • งานล้มเหลว: ตรวจรายละเอียดก่อนสร้างงานใหม่
